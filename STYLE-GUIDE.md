# Task-B Sailing School visual style v0.2

## Style name
Classic Nautical Instruction Chart

## Core description
A mobile-first sailing education interface that looks like a premium printed nautical training chart turned into a clean web app. The visual language combines parchment paper, deep navy ink, orange safety/accent marks, thin compass-line geometry, vector sailing diagrams, and decorative rope-frame corners. It should feel classic, practical, instructor-made, trustworthy, and slightly adventurous; not corporate, not cartoonish, not photorealistic, and not overloaded.

## Colour system
- Parchment background: `#f6efe2`
- Light paper card: `#fbf6ec`
- Deep navy ink: `#0d3145`
- Secondary navy: `#17435a`
- Burnt orange accent: `#f36b08`
- Dark orange: `#c94d00`
- Rope tan: `#c69656`
- Rope dark: `#8f632e`

## Typography
- Main titles: Georgia / Times-style serif, bold, letter-spaced.
- UI text: system sans-serif for readability.
- Labels inside cards: serif, bold, compact, clear.

## UI rules
- Phone-first layout, maximum app width around 470px.
- Large touch targets; minimum practical tap area around 48px.
- Rounded lesson cards with thin tan borders.
- Orange is reserved for action buttons, wind direction, no-go zone and sail accent marks.
- Navy is used for structure, text, compass, icon bodies and linework.
- Decorative elements must never reduce readability.

## Diagram rules
- Always use a direct top-down boat.
- No-go zone is a 90° orange sector at the windward/top side.
- Use a compass/wind circle as the central educational anchor.
- Avoid tiny technical labels; prefer clear visual hierarchy.
