# Task-B Sailing School / Instructional Tool v0.2

A plain HTML/CSS/JavaScript prototype using the new classic nautical instruction-chart style.

## Files

```text
task-b-sailing-school-v02/
├── index.html
├── css/
│   └── styles.css
├── js/
│   ├── app.js
│   ├── router.js
│   └── points-of-sail.js
├── data/
│   └── lesson-content.js
└── STYLE-GUIDE.md
```

## How to run

Open `index.html` in a browser.

For best testing, use a phone-sized responsive viewport in Chrome/Edge dev tools.

## What is included

- Mobile-first Points of Sail screen
- Classic nautical chart UI
- Rope corners and parchment paper feel
- Compass/wind circle with top-down boat
- Orange 90° no-go zone
- Lesson cards for:
  - Close Reach
  - No-Go Zone
  - Close Hauled
  - Beam Reach
  - Broad Reach
  - Run
- Simple lesson interaction
- Placeholder routing for unfinished sections

## Product constraints followed

- No RYA branding
- No copied official syllabus text
- No login
- No backend
- No student personal data
- No paid libraries
- Plain HTML/CSS/JavaScript
