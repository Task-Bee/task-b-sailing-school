Task-B Sailing School v0.2 redesign

Upload these 4 files to the ROOT of your GitHub repository:

- index.html
- styles.css
- app.js
- en.json

In GitHub:
1. Open https://github.com/Task-Bee/task-b-sailing-school
2. Click Add file > Upload files
3. Drag these 4 files into the upload area
4. GitHub should say the files already exist and will be replaced
5. Commit changes
6. Wait 1-2 minutes
7. Open https://task-bee.github.io/task-b-sailing-school/
8. Hard refresh with Ctrl + Shift + R

You do not need to upload old router.js, points-of-sail.js or modules.json for this redesign. They can remain in the repo but are no longer used.
